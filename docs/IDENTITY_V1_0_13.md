# هوية القحطاني — v1.0.13

المرجع البصري المعتمد هو تصميم المستخدم الأسود/الذهبي بحرف «ق» واسم «القحطاني».

## قواعد التطبيق
- الخلفية الأساسية: أسود دافئ `#09090B`.
- الذهبي الأساسي: `#D8AA4F`، مع درجة نص فاتحة `#F1D38E`.
- علامة مختصرة: حرف «ق» واضح وبسيط، دون مؤثرات 3D ثقيلة حتى يبقى مقروءًا في أحجام الأيقونات الصغيرة.
- الاسم الظاهر للمستخدم: «القحطاني» بالعربية؛ الاسم الإنجليزي يبقى فقط للمعرّفات التقنية أو عندما يكون جزءًا من عنوان المحتوى الأصلي.
- لا تظهر مصطلحات Runtime/API/Workers/session للمستخدم النهائي.
- Web وFlutter وAndroid TV وiOS تستخدم نفس اتجاه RTL ونفس الألوان والهوية.

## الأصول الأصلية
لقطة الهوية التي قدمها المستخدم هي المرجع الفني. عند إنتاج App Icon وSplash النهائيين يجب استخدام نسخة مبسطة من العلامة نفسها مع مساحة آمنة مناسبة لأقنعة iOS/Android وعدم وضع نص صغير داخل الأيقونة إذا أصبح غير مقروء.
